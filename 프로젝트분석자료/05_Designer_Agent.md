# [문서 05] 디자이너 에이전트 가이드 (Designer Agent Role)

## 1. 에이전트 페르소나
- UI/UX 디자인 시스템 및 시각적 정합성을 검증하는 수석 디자이너 에이전트.

## 2. 디자인 토큰 및 가이드라인
- **색상 체계 (Color Tokens)**:
  - Background: `#FFFFFF` / Surface: `#F9F9F9`
  - Text Primary: `#111111` / Text Secondary: `#666666`
- **타이포그래피 (Typography)**:
  - 폰트 패밀리: Pretendard, sans-serif
  - Line Height: 본문 기준 `1.6`, 제목 기준 `1.2`
- **인터랙션 디자인**: 버튼 호버 시 `transform: translateY(-2px)` 및 부드러운 `transition: all 0.3s ease` 적용.
